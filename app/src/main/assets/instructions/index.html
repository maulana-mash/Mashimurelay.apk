1. Definisi Software

Mashimurelay adalah perangkat lunak Computer-Aided Design (CAD) dan simulator interaktif teknik kelistrikan industri yang dirancang khusus untuk merancang, menguji, dan menganalisis sistem kendali elektromagnetik, otomasi industri berbasis relai (hardwired relay logic), serta rangkaian tenaga motor listrik.

Mengadopsi standar internasional diagram kelistrikan (IEC 60617 dan NEMA ICS 19-2002), menghadirkan lingkungan virtual real-time di mana setiap komponen kelistrikan dimodelkan secara fisis dan logis sesuai karakteristik aslinya di dunia industri nyata.

2. Kegunaan & Manfaat Utama

  • Perancangan Diagram Kontrol & Tenaga: Menggambar sirkuit kendali dan sirkuit daya pada snap-grid 30px presisi tinggi.
  • Simulasi Logika Relai Real-Time: Memvalidasi fungsi interlocking, penguncian mandiri, urutan sekuensial motor, Forward-Reverse, Star-Delta, hingga otomasi flasher.
  • Analisis & Proteksi Hubung Singkat: Mendeteksi korsleting seketika sebelum diaplikasikan pada panel listrik nyata.
  • Portabilitas & Kompatibilitas Penuh: Bekerja offline di Android dan Windows dengan format berkas .smrl dan .txt.

3. Tujuan Pengembangan

  1. Keamanan Tanpa Risiko: Menghilangkan risiko peralatan meledak, terbakar, atau hubung singkat saat proses belajar dan prototyping.
  2. Efisiensi Waktu & Biaya: Menguji logika sistem kontrol secara instan tanpa perlu merakit kabel secara manual pada papan uji.
  3. Standarisasi Pendidikan Vokasi: Menjadi sarana ajar interaktif untuk teknik elektro, mekatronika, dan instalasi tenaga listrik industri.

1. Navigasi Antarmuka & Kanvas

  • Buka Menu: Ketuk tombol MENU di pojok kiri atas untuk membuka panel navigasi drawer (Workspace, Save, Instructions, Settings, About).
  • Pencarian & Penempatan Komponen: Ketuk tombol LIBRARY di toolbar atau tombol FAB (+) di pojok kanan bawah. Ketuk komponen untuk menempatkannya di kanvas. Geser menggunakan jari (snap 30px otomatis).
  • Rotasi Komponen: Ketuk komponen lalu tekan tombol Putar pada floating pill di bawah kanvas untuk memutar 90 derajat.
  • Pemberian Tag Interlocking: Ketuk komponen lalu tekan tombol Tag untuk menyelaraskan nama interlocking (misal: -KM1) atau mengatur waktu delay (misal: 2.0s).

2. Penarikan Kabel (Wiring System)

  • Arahkan sentuhan ke terminal pin komponen (lingkaran putih/cyan).
  • Ketuk sekali pada pin asal (titik menyala cyan), lalu ketuk pin target pada komponen lain. Kabel ortogonal rapi akan otomatis terbentuk.
  • Proteksi Sambungan Mandiri: Kabel dilarang menghubungkan pin komponen ke pin lain pada komponen yang sama demi kerapian skema.
  • Menggeser Jalur Kabel: Ketuk kabel yang telah terpasang, lalu seret handle tengah kabel untuk mengubah jalur perutean kawat.

3. Menjalankan Simulasi (RUN Mode)

  • Tekan tombol hijau RUN di toolbar atas. Mode simulasi aktif ditandai dengan tombol STOP merah.
  • Sentuh dan tahan tombol Push Button di kanvas untuk mengaktifkan kontak sesaat (momentary press-and-hold).
  • Ketuk Saklar Pemutus atau MCB di kanvas untuk membuka/menutup sirkuit secara permanen.
  • Kabel aktif akan menyala terang (fasa berwarna merah/biru cerah, netral cyan). Motor induksi 3 fasa akan berputar dengan panah dinamis 60fps.
  • Jika terjadi hubung singkat (korsleting), sistem proteksi instan akan memutus daya dan memunculkan banner peringatan SHORT CIRCUIT!.
  • Tekan tombol merah STOP untuk mengakhiri simulasi dan kembali ke mode pengeditan skema.

4. Manajemen File & Penyimpanan

  • Auto-Save: Bekerja secara otomatis saat perubahan dibuat atau saat berpindah aplikasi. Dapat diatur pada menu Settings.
  • Format .smrl: Berkas standar CAD modern berbasis JSON lengkap dengan metadata posisi.
  • Format .txt: Format native Simurelay Android agar dapat dibuka langsung pada pengelola berkas perangkat.

Penutup & Komitmen Pembelajaran

Mashimurelay dirancang sebagai platform terpadu untuk menjembatani teori otomasi kelistrikan dengan implementasi industri nyata. Melalui simulasi berpresisi tinggi ini, perancang dapat memvalidasi desain sistem kendali tanpa risiko kesalahan perangkat keras.

Peringatan Keselamatan Instalasi Fisik Nyata:
Selalu patuhi standar K3 Listrik dan prosedur Lockout/Tagout (LOTO). Pastikan sumber tegangan telah dimatikan total dan ukur dengan voltmeter sebelum menyentuh kabel pada panel industri fisik. Hasil simulasi virtual ini adalah panduan konseptual dan verifikasi logika matematis.
